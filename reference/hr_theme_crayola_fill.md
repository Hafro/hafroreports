# crayola fills

crayola fills

## Usage

``` r
hr_theme_crayola_fill(n = 100, ...)
```

## Arguments

- n:

  Defines Length of color entries in the vector of palettes is
  calculated as n\*12 (this length should be longer than levels filled).

- ...:

  Additional arguments passed to ggplot2::scale_fill_manual.

## Value

Functions the same as ggplot2::scale_fill_manual but with color palette
vector defined according to the 'crayola' spectrum
