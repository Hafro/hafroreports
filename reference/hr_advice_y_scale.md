# Y axis for advice sheet figures

Starts at 0, with the top and breaks following the data, so figures fit
any stock.

## Usage

``` r
hr_advice_y_scale(...)
```

## Arguments

- ...:

  Passed to
  [`ggplot2::scale_y_continuous()`](https://ggplot2.tidyverse.org/reference/scale_continuous.html).

## Value

A ggplot2 scale.
